# Aula de Git e GitHub

Git: é uma ferramenta usada para controlar e acompanhar as alterações feitas em um projeto.
GitHub: é um site onde podemos guardar os projetos do Git e acessá-los pela internet.
Push: envia as alterações do computador para o GitHub.
Pull: pega as alterações que estão no GitHub e traz para o computador.

Criar um sistema simples para cadastro e consulta de alunos.

## Tecnologias
-PHP: é uma linguagem usada para programar sites, principalmente a parte que acontece por trás da página, como login, cadastro e banco de dados.

-HTML: é usado para montar a estrutura do site, como títulos, textos, imagens, links e botões.

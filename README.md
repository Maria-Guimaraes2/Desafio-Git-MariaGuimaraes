Git: é uma ferramenta usada para controlar e acompanhar as alterações feitas em um projeto.
GitHub: é um site onde podemos guardar os projetos do Git e acessá-los pela internet.
Push: envia as alterações do computador para o GitHub.
Pull: pega as alterações que estão no GitHub e traz para o computador.
